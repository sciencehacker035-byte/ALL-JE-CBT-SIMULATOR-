# Civil JE CBT Exam Simulator — GitHub Pages

## Included
- Responsive CBT dashboard
- RRB JE / SSC JE / HPCL JE
- Technical + Non-Technical
- Timer and configurable negative marking
- Question palette
- Mark for Review
- Clear Response
- Bookmarks
- Result + detailed review
- Wrong-question memory
- Revision queue
- Weak-topic detection
- Performance history
- Import/export progress
- Dark/light mode
- Resume unfinished test after refresh
- Static GitHub Pages deployment
- No backend/API required

## Root files
Keep these two files in the same repository root:
- `index.html`
- `style.css`

The supplied final HTML is self-contained for the application logic and references only the root `style.css`.

## Important
The starter question bank is a demo/practice bank. Do not label unverified generated questions as official PYQs.

Exam patterns can change. Verify the current official notification before using exact mock-exam presets.

Official references:
- RRB JE CEN 03/2024: https://www.rrbcdg.gov.in/uploads/202403/CEN%2003%202024_JE.pdf
- SSC JE scheme: https://ssc.gov.in/api/attachment/uploads/masterData/Static/JE.pdf
- HPCL Selection Methodology: https://www.hindustanpetroleum.com/documents/pdf/Selection_Methodology_for_Recruitment_of_Officers_04082025.pdf

## Deployment
1. Replace the existing `index.html` with the supplied final HTML.
2. Replace `style.css` with the supplied final CSS.
3. Commit to `main`.
4. GitHub Settings → Pages → Deploy from branch → `main` → `/ (root)`.
5. Open the GitHub Pages URL.
